# E23-T05 · Commit dialog

## What it is

The **Commit dialog** lets the user check which changed files go into a commit and optionally write the message before running a commit, push or PR action. Leaving the message empty makes the server generate one.

## When it is used

When the user picks Commit, Push or Create PR from the Git actions menu and wants to review first, for example to leave out a scratch file the agent created.

## How it works today

- **Entry points:** Commit, Push and Create PR menu items in the Git actions control (E23-T04); overflow menu on small screens.
- **Behaviour to preserve:**
  - File exclusion is a set; `filePaths` are sent to the stacked action only when the selection is partial.
  - Commit buttons are disabled when no file is selected.
  - "Commit on new branch" creates a feature branch and commits there.
  - Cancel clears the message, exclusions and edit mode.
  - Empty message → server text generation (E23-T10) with the configured writing style.
  - The default-branch confirmation (E23-T06) applies when the chosen action pushes or opens a PR.
- **Surfaces:** web and desktop. Mobile has a separate commit sheet with the same options (E33-T01). The diff panel's Changes sidebar has a commit box that commits staged changes (E18-T03).
- **Where the code lives:** `apps/web/src/components/GitActionsControl.tsx:1876–2038`, constants at `:371`.

## Problems today

- Two commit UIs in the web app (this dialog with an exclusion list, and the diff panel's stage-based commit box) with different models of "what is committed": excluded files here, staged files there.
- The dialog is embedded in the 2,092-line Git actions file.

## Remodel goals

- **Experience:** one commit component used from the header and the diff panel, with one selection model. Show diff stats per file and let a click reveal the file in the diff panel (match cut into the diff, design direction 3.8) rather than an external editor only.
- **Motion:** dialog uses the standard dialog preset; checkbox state is instant (design direction 3.10).

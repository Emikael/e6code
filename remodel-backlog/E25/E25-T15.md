# E25-T15 · Open source licenses

## What it is

The Open source licenses page (`/settings/open-source-licenses`, a detail page under General): the list of third-party software that E6 Code ships with and the full text of each licence or notice, plus a link to the project's own source. The list is generated at build time, so it always matches what is bundled.

## When it is used

- Legal or compliance checks of what the app includes.
- Curiosity about a dependency; finding its licence text.

## How it works today

- **Entry points:** General → Diagnostics → Open source licenses → "View licenses"; deep link; mobile Settings → About E6 Code → Open source licenses (list and detail routes).
- **Behaviour to preserve:** "Project source" row; "Third-party notices" section with a count, a search field ("Search licenses"; Esc clears it), expandable entries showing the full notice text; manifest fetch error ("The license manifest could not load.") with retry; loading state.
- **How the data is made:** a Vite plugin (`thirdPartyLicensesPlugin` in `apps/web/vite.config.ts`, config `third-party-licenses.config.json`) generates `third-party-licenses.json` from the bundled packages; packages without a distributable licence or notice fail the build until an override is added; `vp run licenses:sync` refreshes notices. The page fetches the JSON at runtime. Mobile has its own generated list (`mobileThirdPartyLicenses.ts`).
- **Surfaces:** web, desktop; mobile separate (E34-T08).
- **Where the code lives:** `apps/web/src/components/settings/OpenSourceLicenses.tsx`, `scripts/lib/third-party-licenses.ts`, `scripts/sync-third-party-license-notices.ts`.

## Problems today

- The list is not virtualised; expanding long notices in a long list is heavy.
- Not in settings search.

## Remodel goals

- **Experience:** fast search with match highlighting, grouped by licence type, readable long text in a mono-free body style.
- **Performance:** virtualised list; the manifest is fetched only when the page opens.

## Done when

- [ ] Count, search, expandable full text, project source link, error with retry preserved.
- [ ] New v2 dependencies (motion, icon set, any fonts) appear automatically through the build plugin, with any required overrides added.
- [ ] Virtualised; dark and light; keyboard reachable.

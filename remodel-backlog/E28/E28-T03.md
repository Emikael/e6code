# E28-T03 · Custom model prices

## What it is

The **Custom model prices** dialog: lets a user override the per-model token prices used for cost estimates (input, output, cached input), for models the built-in rate table does not know or prices the user disagrees with. Overrides are saved in each selected environment's settings.

## When it is used

- A model shows as "unknown cost" on the Usage page.
- A user wants estimates to reflect a negotiated or different price.
- Undoing overrides with "Reset to automatic".

## How it works today

- **Entry points:** Usage → environment filter menu → **Model prices**.
- **Behaviour to preserve:** environment selection ("Apply to", initialised from the Usage page's environment selection); a table of model, input, output and cached prices with add row; Mixed values when environments disagree; Save changes with per-environment save results and "Retry failed saves" on partial failure; "Reset to automatic"; validation of price fields (`usagePriceForm.ts`); stored as server `usagePriceOverrides` on each selected environment.
- **Surfaces:** web and desktop; the setting is server-side, so mobile totals reflect it (mobile has no editor; not verified).
- **Where the code lives:** `apps/web/src/components/usage/UsagePriceOverrides.tsx` (554), `usagePriceTable.ts`, `usagePriceForm.ts`, `usagePriceTargets.ts` (all with tests); server `usage/usagePricing.ts`.

## Problems today

- Hidden at the bottom of a filter menu; the "unknown cost" flag on a model does not link to it.
- A second, separate multi-environment write path with its own Mixed and retry logic, parallel to the settings scope (E25-T02).

## Remodel goals

- **Experience:** reachable from an unknown-cost model row ("Set price") and from Settings; prefilled with the automatic price so the user edits rather than types from scratch.
- **Motion:** standard dialog moment; a failed save uses error text, not motion.

## Done when

- [ ] Environment selection, table editing, Mixed, partial-failure retry and reset to automatic preserved (tests ported).
- [ ] Reuses the settings scope write path, or the separate path is kept by decision.
- [ ] Reachable from unknown-cost rows; dark and light; keyboard reachable.
